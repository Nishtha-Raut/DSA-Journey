## 👋 About This Repository

**DSA-Journey** is my personal repository for learning, practicing, and documenting **Data Structures & Algorithms**.

I use this repository not just to store solutions, but to understand the complete problem-solving process:

**Problem → Intuition → Approach → Implementation → Complexity → Learning**

The repository contains problems solved from platforms such as **LeetCode** and **GeeksforGeeks**, along with explanations written in both **English and Hinglish** to make concepts easier to revise and understand.

> 💡 **The goal is not just to solve problems, but to understand why the solution works and how to approach similar problems in the future.**

# 📚 How Each Problem Is Documented

Each problem follows a structured **4-file documentation system**:

```text
Problem Folder
│
├── question.md
├── explanation-english.md
├── explanation-hinglish.md
└── solution.java
```

### 📄 `question.md`

Contains the complete problem information:

* Problem title
* Difficulty
* Original problem link
* Problem statement
* Input / Output
* Examples
* Constraints
* Hints
* Notes

### 🇬🇧 `explanation-english.md`

Contains the complete explanation in simple English:

* Intuition
* Approach
* Why the approach works
* Dry run
* Time Complexity
* Space Complexity
* Edge Cases
* Interview Takeaway

### 🇮🇳 `explanation-hinglish.md`

The same concept explained in **simple Hinglish** for easier understanding and revision.

### ☕ `solution.java`

Contains the Java implementation of the solution with simple comments explaining the important parts of the code.

# 🔄 My Problem-Solving Process

I try to follow a consistent process while solving problems:

```text
           🧩 Understand the Problem
                    ↓
           🔎 Identify the Pattern
                    ↓
            💡 Build the Intuition
                    ↓
             ✍️ Design Approach
                    ↓
             💻 Write the Code
                    ↓
             🧪 Test Edge Cases
                    ↓
          ⏱️ Analyze Complexity
                    ↓
             📝 Document Learning
                    ↓
              🔁 Revise & Improve
```

This helps me focus on **problem-solving patterns** instead of memorizing individual solutions.
