## 🧠 About This Repository

**DSA-Journey** is my personal repository for learning and practicing **Data Structures & Algorithms**.

It contains problems solved from platforms like **LeetCode** and **GeeksforGeeks**, along with detailed explanations of the solutions.

The purpose of this repository is not just to store code, but to understand:

> **How to approach a problem, why a solution works, and how to analyze its efficiency.**

Each problem is documented with its **approach, intuition, solution, and complexity analysis**.
